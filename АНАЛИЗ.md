# Мониторинг отзывов о LUDUS — технический анализ

> Автоматическая система: 3×/день проверяет площадки на новые отзывы о клубе, красиво показывает их с разбивкой по дням, шлёт дайджест в Telegram и отдельный аларм на низкие оценки.

## 1. Главный фактор — откуда берутся отзывы

Вся сложность и стоимость проекта зависит НЕ от Telegram и не от дашборда, а от способа достать отзывы с каждой площадки. Тут три мира:

| Источник | Способ доступа | Стоимость |
|---|---|---|
| **Google Maps / Business Profile** | Официальный **Google Business Profile API** — но только если вы **владелец верифицированного профиля** клуба. Отдаёт отзывы, оценки, позволяет отвечать. | **Бесплатно** |
| **Facebook / Instagram** | **Graph API** — если вы админ страницы/аккаунта клуба (отзывы FB, упоминания/комментарии IG). | **Бесплатно** |
| **TripAdvisor** | Официального открытого API на чтение отзывов нет (только партнёрский). Практически — скрапинг или сторонний сервис. | Платно/серо |
| **Яндекс.Карты, 2GIS, Google (если НЕ владелец)** | Нет бесплатного официального API → сторонний скрапер (Outscraper ~$2/1000 отзывов, SerpApi 100 бесплатных запросов/мес, Bright Data 5k/мес free). | Платно (есть free-tier) |

**Вывод:** если LUDUS владеет своим Google-профилем и страницей Facebook — основные площадки закрываются **бесплатно и легально** через официальные API. Всё, что вне вашего владения (TripAdvisor, чужие карты) — либо платный скрапер, либо ручками.

## 2. Архитектура системы

Пять простых блоков (тот же принцип, что во всех наших проектах: код собирает и структурирует, ИИ — судит и оформляет):

```
[Сборщик] → [Хранилище] → [Анализ (ИИ)] → [Уведомления] → [Дашборд]
```

1. **Сборщик** — по расписанию 3×/день ходит в каждый источник, забирает отзывы, **дедуплицирует** (хранит ID уже виденных, чтобы не дублировать), приводит к единому виду: `{источник, автор, оценка, текст, дата, ссылка}`.
2. **Хранилище** — накопительный JSON/БД, отзывы копятся по дням (как история в других наших проектах).
3. **Анализ (ИИ, опционально)** — перевод (отзывы на TH/RU/EN), короткое саммари, тема/тег («тренеры», «чистота», «цена»), и — приятный бонус — **черновик ответа** для ответственного. Оценку (звёзды) берём готовую из источника, ИИ для неё не нужен.
4. **Уведомления** — Telegram-бот (см. §3).
5. **Дашборд** — HTML с разбивкой по дням, средней оценкой, динамикой (как калькулятор). Варианты хостинга: GitHub Pages / живой артефакт.

## 3. Уведомления — Telegram (твой предпочтительный вариант)

Лучше почты: мгновенно, на телефоне, видно всей команде в группе.

- **Дайджест 3×/день** — бот постит в группу: новые отзывы за период, средняя оценка, ссылки.
- **Аларм на низкую оценку** — при отзыве **< 3★** бот сразу шлёт отдельное выделенное сообщение с текстом отзыва, ссылкой и черновиком ответа.
- Два порога: **< 4★** — подсвечиваем в дайджесте; **< 3★** — отдельный аларм.

⚠️ Нюанс: при опросе 3×/день «мгновенный» аларм придёт в момент следующей проверки (задержка до ~8 ч). Если нужен реально мгновенный — у Google Business Profile есть push-уведомления о новых отзывах (через Pub/Sub). Это апгрейд на потом.

## 4. Где запускать (runtime)

| Вариант | Плюсы | Минусы |
|---|---|---|
| **Встроенный планировщик Cowork** | ноль инфраструктуры, 3×/день из коробки | зависит от доступности агента |
| **launchd на Маке** | бесплатно, под контролем | работает, пока Мак включён |
| **Небольшой VPS (~$5/мес)** | 24/7, надёжно, тот же сервер что под вебхуки | платно (флажок по бюджету) |

Для батча 3×/день годится любой; для продакшена стабильнее VPS.

## 5. Ресурсы и стоимость (чеклист)

**Бесплатно:**
- Google Business Profile API (если владелец профиля) — OAuth-доступ.
- Facebook/Instagram Graph API (если админ страницы).
- Telegram-бот (@BotFather) + группа.
- Запуск на Маке/планировщике Cowork.

**Платно (флажок по бюджету, только если реально нужно):**
- Скрапер для площадок без API (Outscraper ~$2/1000, SerpApi/Bright Data — free-tier).
- Claude API — если анализ (перевод/саммари/черновик ответа) должен идти полностью без участия человека. Для дневного объёма отзывов — копейки; на Max можно гонять вручную бесплатно.
- VPS ~$5/мес — если нужен 24/7.

**Ориентир:** при владении Google-профилем и FB-страницей систему можно поднять **почти бесплатно**. Платное появляется только ради TripAdvisor/чужих карт или полной автономности.

## 6. Готовые решения (прайор-арт)

- **GitHub:** боты «отзывы → Telegram» есть, но под App Store / Google Play (`gp-reviews-tgrm-bot`, `app-review-monitor`), не под Google Maps бизнес-отзывы. Паттерн переиспользуем, код — нет.
- **Коммерческие SaaS:** Birdeye, Synup, Sprout Social — делают ровно это (агрегация Google/FB/TripAdvisor + алерты + ответы), но платная подписка и избыточно для одного клуба.
- Вывод: свой лёгкий инструмент под наши источники оправдан.

## 7. Моё предложение по оптимизации

1. **Начать с одного источника, который решает 80% — Google Maps** (по нему живут и умирают клубы). Довести цепочку до конца: сбор → дедуп → Telegram-дайджест 3×/день + аларм <3★ → простой дашборд. Потом добавлять источники по одному.
2. **Официальные бесплатные API там, где вы владелец** (Google, FB) — не связываться со скрапингом, пока не приперло. Меньше денег, меньше поломок.
3. **Telegram-группа + бот** с черновиком ответа и прямой ссылкой на отзыв — ответственный отвечает в один клик.
4. **Апгрейд на будущее:** push от Google (Pub/Sub) для мгновенных алармов вместо опроса.

## 8. Что нужно от тебя, чтобы двигаться

## 10. Где запускать — разница вариантов + роль GitHub

| Вариант | Как работает | Надёжность | Цена |
|---|---|---|---|
| **Мак + launchd** | скрипт запускается по расписанию на твоём Маке | только когда Мак включён и не спит → может пропустить запуск | бесплатно |
| **Планировщик Cowork** | по расписанию поднимается агент и делает работу | зависит от доступности агента; удобно для «умных» дайджестов | бесплатно |
| **VPS (~$5/мес)** | всегда включённый сервер в облаке | 24/7, полный контроль | платно |
| **GitHub Actions** ⭐ | GitHub по расписанию (cron) сам запускает наш скрипт в облаке | 24/7, не зависит от твоего Мака | **бесплатно** |

**GitHub здесь — не только хостинг страницы, а полноценный движок.** Три роли сразу:

1. **GitHub Actions** = бесплатный «будильник + исполнитель»: по cron 3×/день запускает сборщик прямо на серверах GitHub. Мак может быть выключен.
2. **Репозиторий** = хранилище: после каждого запуска коммитим новые отзывы и список уже виденных ID (дедупликация переживает перезапуски).
3. **GitHub Pages** = бесплатный хостинг дашборда (как у калькулятора).

Секреты (токен Google, токен Telegram-бота, ключ скрапера) хранятся в **GitHub Actions Secrets** — зашифрованы, в коде их нет. Репозиторий делаем **приватным** (отзывы публичны, но внутренние заметки/ответы — нет; приватных Actions-минут бесплатного тарифа хватает с запасом).

**Вывод:** для батча 3×/день **GitHub Actions — лучший баланс**: всегда работает, ничего не арендуем, Мак не нужен. Это и есть ответ на «можем ли использовать GitHub» — да, по максимуму.

## 11. Рекомендованная схема Этапа 1 (Google → Telegram, почти бесплатно)

```
GitHub Actions (cron 3×/день)
  └─ сборщик: тянет отзывы Google → дедуп по ID (state в репо)
       ├─ коммитит новые отзывы в репозиторий
       ├─ Telegram-бот: дайджест в группу + отдельный аларм на <3★
       └─ пересобирает дашборд → GitHub Pages
```

- **v1 — без ИИ и бесплатно:** оценка (звёзды) и текст берём как есть из источника. Работает на нуле.
- **v2 — добавить ИИ (Claude API, копейки):** перевод TH/RU/EN, короткое саммари, тема-тег и черновик ответа в аларме.
- **Доступ к Google-отзывам — развилка:**
  - *Официальный Google Business Profile API* — бесплатно навсегда, но нужен запрос доступа у Google + настройка OAuth (пара дней на одобрение).
  - *Скрапер (SerpApi/Bright Data/Outscraper, есть free-tier)* — почти без настройки, и **тем же способом берёт TripAdvisor и оба дубль-листинга**. При нашем объёме (несколько новых отзывов в день) — в пределах бесплатного тарифа или копейки.
  - Поскольку TripAdvisor всё равно требует скрапера, **один скрапер на оба источника — самый ровный путь**; официальный API оставляем как «чистый бесплатный» запасной для Google.
